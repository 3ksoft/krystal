# misc

One-off experiments and diagnostics kept because they may still be useful.
They are not part of the supported runtime surface and may lag behind package APIs.

- `analyze-vocab.ts` — tokenizer/vocabulary exploration
- `bench_matmul.ts` — standalone matmul experiment
- `convert_gguf_to_wq4.ts` — early WQ4 converter
- `inspect.ts` — GGUF/LFM2 metadata inspection
- `pi.ts` — native/Deno inference harness
- `probe-memory.ts` / `probe-web.ts` — WebGPU allocation probes
- `probe*.html` — browser probe pages
